routok

API 使用说明

按下面步骤创建令牌，并将 routok 接入 Codex、Claude 或 Gemini。

打开令牌管理
访问 routok.com

一、创建 API 令牌

登录 routok 后台

打开 令牌管理，点击“添加”，创建一个新令牌。

选择模型分组

按实际需要选择 Codex、Claude 或 Gemini 分组，并保存令牌。请妥善保管密钥，不要公开分享。

充值账户

支持在线充值和兑换码充值。充值完成后，再进行下方工具配置。

二、配置 AI 工具

先安装 Node.js 22 或更高版本，再按所用工具配置。

Codex

安装并验证：

npm install -g @openai/codex --registry=https://registry.npmmirror.com
codex --version

编辑 ~/.codex/config.toml：

model_provider = "routok"
model = "gpt-5.4"

[model_providers.routok]
name = "routok"
wire_api = "responses"
requires_openai_auth = true
base_url = "https://routok.com/v1"

编辑 ~/.codex/auth.json，将令牌填入：

{ "OPENAI_API_KEY": "你的令牌" }

Claude

安装并验证：

npm install -g @anthropic-ai/claude-code
claude --version

在 ~/.claude/settings.json 中填入令牌和服务地址：

{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的令牌",
    "ANTHROPIC_BASE_URL": "https://api.routok.com"
  }
}

Gemini CLI

安装并验证：

npm install -g @google/gemini-cli
gemini --version

在 ~/.gemini/.env 中填入：

GEMINI_API_KEY="你的令牌"
GOOGLE_GEMINI_BASE_URL="https://routok.com"

三、图形化工具（可选）

不熟悉命令行时，可以使用一键配置工具或 CC-Switch，按工具提示选择 routok 并粘贴令牌。

常见问题

认证失败：检查令牌是否完整、是否过期，并确认配置文件中的地址没有多余空格。

连接失败：保存配置后重新打开终端或工具；确认使用的是对应工具的配置文件。

更换模型：修改配置中的模型名称，使用 routok 后台当前支持的模型。
