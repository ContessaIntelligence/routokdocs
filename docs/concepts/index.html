接入前需要了解的概念

一次模型调用通常经过：你的应用 → RouTok → 模型服务商。先理解地址、密钥、模型和额度，接入时就更容易定位问题。

登录账号与模型密钥

凭据获取方式用途
账号与登录密码注册或由管理员开通登录控制台，查看余额和管理自己的密钥
模型 API 密钥在 API 密钥页面创建在客户端或应用中调用模型

浏览器登录凭据用于控制台会话，不应作为应用的长期 API Key。普通客户端使用本站的模型 API 密钥。

API 地址与完整路径

名称 示例 用在哪里
API 根地址 https://api.routok.com 本指南的 ROUTOK_BASE_URL
SDK 基础地址 https://api.routok.com/v1 OpenAI SDK 的 base_url／baseURL
完整接口地址 https://api.routok.com/v1/chat/completions 直接 HTTP 请求

部分软件会自动添加版本路径。请按客户端配置说明填写，避免重复出现 /v1/v1。

模型与分组

  • 模型 ID：请求中的模型标识，通常填写在 model 字段。请从模型广场或当前密钥返回的模型列表复制完整 ID。
  • 分组：密钥页面可选的使用范围，不同分组的可用模型和价格可能不同。请选择支持目标模型的可用分组。

模型无法调用时，先核对模型 ID、密钥的模型限制和所选分组。仍无法解决时，请提供脱敏错误信息并联系管理员。

额度与 Token

额度是预算，Token 是用量，API Token 是凭据。 三者名称接近，含义不同。

账户余额、密钥额度和套餐限制分别生效。调用提示额度不足时，先核对自己的钱包、密钥状态和套餐周期；仍无法解决时联系管理员。
