连接聊天软件与应用

准备 API 地址、模型 API 密钥、模型 ID，即可配置支持自定义接口的软件。建议先完成一次在线测试，再验证客户端连接。

准备三个配置值

客户端字段 填写内容 获取位置
API Key／Token 本站签发的完整模型密钥 API 密钥
Base URL／API 地址 与客户端协议匹配的接入地址 密钥页面的 API 地址
Model／模型 ID 完整模型标识 模型广场或模型列表 API

服务商名称可填写“RouTok”。Provider／接口类型应选择模型支持的协议，例如 OpenAI 兼容。

地址是否需要 /v1

RouTok 的 API 根地址为 https://api.routok.com，按客户端要求填写：

客户端要求 应填写
OpenAI SDK 的 base_url／baseURL https://api.routok.com/v1
自动添加 /v1 的服务商模板 https://api.routok.com
明确要求完整 Chat Completions 地址 https://api.routok.com/v1/chat/completions

以上为可直接使用的 RouTok API 地址。控制台和账户管理请访问 api.routok.com；模型调用也使用该域名，按客户端要求填写根地址或 /v1 地址。

CC Switch、Codex 与 Claude Code

初次使用建议按“安装编程工具 → 用 CC Switch 配置 → 发消息验证”的顺序操作。工具配置速查提供可复制的安装命令和配置示例。

CC Switch：图形化切换配置

CC Switch 用来管理 Codex、Claude Code 等工具的服务地址与密钥；实际对话仍在对应编程工具中进行。打开 CC Switch 官方下载页，选择自己系统的安装包：Windows 通常选择 Windows.msi，ARM 设备选择 arm64 包，macOS 选择 macOS 安装包，Linux 按发行版选择。

  1. 先安装下方的 Codex CLI 或 Claude Code，再打开 CC Switch，选择对应工具标签。
  2. 点击“添加供应商”；如果列表没有 RouTok，使用自定义配置，名称填写 RouTok，密钥填写在 RouTok 创建的模型 API 密钥。
  3. Codex 的 Base URL 填 https://api.routok.com/v1，协议选择 Responses；Claude Code 的 Base URL 填 https://api.routok.com。模型填写该密钥可用的完整模型 ID。
  4. 保存并启用该供应商，重新打开编程工具。不同版本的按钮名称可能略有不同，详见 官方添加供应商说明。

Codex：在项目中使用 AI 编程

Codex 是 OpenAI 的编程助手。接入 RouTok 可先使用终端中的 Codex CLI：安装 Node.js LTS，重新打开终端，运行 npm install -g @openai/codex，再用 codex --version 检查。也可从 官方 Releases 下载对应系统的 CLI，其他产品入口见 Codex 官方说明。

用 CC Switch 配好 RouTok 后，在项目文件夹打开终端并输入 codex，发送“请介绍这个项目的目录结构”。手动配置见 Codex 配置示例。

Claude Code：在终端中阅读和修改代码

这里使用 Claude Code 命令行工具。打开 Claude Code 官方安装页，按系统安装；Windows 在 PowerShell 运行 irm https://claude.ai/install.ps1 | iex，macOS / Linux 运行 curl -fsSL https://claude.ai/install.sh | bash。安装完成后重新打开终端，运行 claude --version 验证。

用 CC Switch 配好 RouTok 后，在项目文件夹打开终端并输入 claude，完成首次启动提示，再发送“请介绍这个项目的目录结构”。手动配置与选择模型见 Claude Code 配置示例。

收到回复后，到 RouTok 用量日志核对记录。若提示找不到命令，重新打开终端并检查安装结果；若出现 401 或模型不存在，核对密钥、分组、模型 ID 和当前启用的供应商。

Cherry Studio

  1. 打开设置中的模型服务商页面，选择或创建兼容服务商。
  2. 选择支持 OpenAI 兼容接口的服务商配置，按客户端要求填写本站 API 地址。
  3. 填入模型 API 密钥并启用服务商。
  4. 获取模型列表，或手动添加从本站复制的模型 ID。
  5. 新建会话并选择该服务商的模型，发送一条短消息。

OpenAI 模板和不同客户端版本的补路径规则可能不同，以字段提示为准。配置入口可参考 Cherry Studio 官方说明。

Dify 与工作流应用

由工作区管理员添加支持自定义地址的模型服务商，再在工作流节点中选择对应模型。聊天、向量和重排序节点分别需要支持该任务的模型。配置入口见 Dify 官方说明。

确认连接成功

完成一条消息，收到回复，并在 RouTok 用量日志找到对应记录。客户端的“连接成功”提示有时只验证密钥或模型列表，仍需实际生成一次内容。

现象 检查方法
401 核对完整密钥及有效期，确认未填写密码或 PAT
404 检查是否重复添加 /v1，或误填完整接口路径
模型不存在 使用模型 ID，避免填写展示名称
网页正常，软件失败 核对密钥的分组和模型限制

其他情况见错误排查。
