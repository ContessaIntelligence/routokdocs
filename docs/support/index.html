联系支持

账号、充值、套餐、模型开放和本站价格问题，请通过 RouTok 的站内支持渠道处理。调用问题可以先查看错误排查。

查找联系方式

使用站内公告、页脚或关于页面展示的联系方式。支付和账号问题不应提交到 New API 项目的公共问题区。

分享信息前检查

保留定位问题所需的状态、时间和记录标识。遮挡密码、验证码、恢复码、完整 API 密钥、浏览器登录令牌、完整支付凭据和私人文件。

等待处理期间

保留原始订单号或任务 ID，避免反复提交相同支付或生成请求。确认凭据泄露时，先停用并更换，再继续核对异常记录。
