余额、充值与套餐

在钱包查看账户余额、订单和套餐状态。接入前确认可用额度，购买前核对到账额度、有效期及适用范围。

充值与到账

  1. 选择钱包中提供的金额和支付方式。
  2. 核对订单金额、到账额度及购买说明。
  3. 完成支付后返回本站，刷新钱包或订单列表。
  4. 确认订单状态及余额更新，再继续调用。

充值不到账时，先确认支付结果，并保留订单号、支付时间和金额，通过站内支持核对。避免重复支付同一笔订单。

使用兑换码

在钱包的兑换入口填写完整兑换码并提交。提示无效时，检查首尾空格、字符和使用状态。兑换码属于敏感凭据，反馈问题时请遮挡完整内容。

选择套餐

购买前重点查看：

项目 需要确认
可用范围 支持的模型和分组
可用额度 总量、次数及其他限制
有效期 开始时间、到期时间和重置周期
扣费方式 套餐与账户余额的使用顺序

如页面提供扣费偏好，可按用途选择。实际扣费来源以用量记录和套餐状态为准。

余额不足时检查什么

账户余额、密钥额度和套餐额度是三层不同限制。账户有余额时，密钥仍可能到期或额度耗尽；套餐有效时，也可能已达到本周期限制。

先看错误说明，再分别核对钱包、密钥设置和套餐状态。费用明细见计费说明。

退款、发票、优惠及支付处理时效以本站购买页面和正式服务说明为准。
