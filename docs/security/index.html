账号安全与访问管理

在安全与访问管理登录方式和设备会话。完成初次接入后，建议检查以下设置。

保护登录方式

  • 使用独立密码，并保存在可信的密码管理器中。
  • 按页面支持情况启用双因素验证（2FA）或通行密钥（Passkey）。
  • 启用验证前确认绑定邮箱可用，按提示妥善保存恢复码。
  • 新的验证方式配置完成后，确认验证成功，再退出当前设备。

恢复码、验证码和重置链接都可用于敏感操作，只能由本人保管和使用。

检查登录设备

结合登录时间、设备类型和 IP 判断会话是否属于自己。代理和移动网络可能改变 IP，单个陌生地址不足以确定账号被盗。

发现可疑活动时，撤销对应会话、修改密码，并检查模型密钥和调用记录。安全信息变更后，其他设备可能需要重新登录。

区分登录会话与 API 凭据

类型 用途 停用位置
浏览器登录会话 访问控制台 安全与访问中的设备会话
模型 API 密钥 聊天、图片等模型调用 API 密钥
个人访问令牌 PAT 管理 API 自动化 安全与访问中的个人访问令牌

退出浏览器不会自动停用应用的 API 密钥。怀疑密钥泄露时，按密钥泄露处理步骤更换凭据。

无法完成验证

优先使用页面提供的恢复入口。丢失设备或恢复方式时，联系支持了解处理流程。支持排查无需你的密码、验证码、恢复码或完整密钥。
