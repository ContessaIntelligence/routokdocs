常见问题

有账号，为什么还不能调用

调用还需要可用额度、可用模型和模型 API 密钥。账号密码用于登录网站，不能填写到客户端的 API Key 字段。

API 地址需要加 /v1 吗

OpenAI SDK 通常使用“API 根地址 + /v1”；部分客户端模板会自动追加。填写方法见客户端接入。

模型 ID 在哪里找

从模型广场复制完整 ID，或使用当前密钥查询 GET /v1/models。展示名称和上游名称不一定就是本站调用 ID。

为什么账户有余额仍提示额度不足

账户余额、密钥额度和套餐限制分别生效。请核对密钥状态、有效期及套餐周期，见钱包说明。

充值成功但没有到账怎么办

先确认支付结果，保留订单号、金额和支付时间，再通过站内支持核对。避免重复支付。

Token、令牌和额度有什么区别

Token 是模型用量单位，API 令牌是调用凭据，额度是可使用预算。见核心概念。

为什么对话越长，费用越高

客户端通常会将历史消息再次发送给模型，输入用量随之增加。文件、图片和多轮工具调用也可能增加消耗，见计费说明。

更换模型只需要改名称吗

基础聊天可能如此，但上下文、输出参数、工具和多模态能力仍需重新验证。建议先用代表性请求测试。

关闭网页会停止生成吗

不保证。上游请求或异步任务可能继续运行，先查询任务状态和用量记录，再决定是否重发。

忘记密码或丢失验证设备怎么办

忘记密码可使用找回密码。验证设备丢失时，使用页面提供的恢复方式；无法完成时联系站内支持了解核验流程。

为什么看不到某个功能

先确认已登录正确账号。功能入口可能受网站配置、账号权限或模型能力限制，可以通过站内支持确认。

是否支持退款、发票或固定折扣

以本站购买页面、服务条款和支持人员提供的正式说明为准。

可以把密钥发给别人协助配置吗

请自行填写完整密钥，分享脱敏配置。已泄露时，立即停用旧密钥并更新应用，见密钥泄露处理。
