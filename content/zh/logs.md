# 查看用量与调用记录

[用量日志](/usage-logs)用于确认请求是否到达本站、定位调用问题，以及核对实际费用。

## 找到一条记录

1. 选择包含请求时间的时间范围。
2. 按模型、密钥名称等条件筛选。
3. 找到对应记录，查看用量、耗时和费用。
4. 有详情入口时展开，核对计费明细或失败原因。

![New API 用量日志示例，展示时间、模型、Token 和费用列](/images/usage-logs.zh-CN.jpg)

*① 按时间和模型筛选，② 核对调用模型，③ 查看耗时与详情。截图为项目模拟数据，包含管理员可见列；普通用户仅能查看自己的记录。*

## 常见字段

| 字段 | 含义 |
| --- | --- |
| 模型 | 此次请求记录的模型标识 |
| 输入／输出 | 模型处理量，Token 不能直接当作字数 |
| 缓存明细 | 支持时展示缓存读取、写入等分类 |
| 耗时 | 请求时间指标；首字延迟与总耗时分别反映不同阶段 |
| 费用／额度 | 按页面单位展示的消耗 |
| 状态／失败原因 | 用于判断权限、参数、额度或上游问题 |

图片和视频可能另有任务记录。任务尚未结束时，最终费用也可能尚未产生。

## 找不到记录

先核对账号、API 地址、时间范围和筛选条件，再刷新页面。部分请求在进入处理前被拒绝，因此没有日志并不等于请求没有发送。

对照客户端日志时，请注明时区，例如“北京时间 2026-10-21 14:30”。

## 对费用有疑问

提供发生时间、模型和记录标识，通过[站内支持](/docs/support)核对。截图中保留必要的用量与状态信息，遮住完整密钥、私人提示词和文件内容。计费单位的解释见[费用说明](/docs/costs)。
