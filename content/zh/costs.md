# 看懂用量与费用

调用前在[模型广场](/pricing)查看价格和计费单位，调用后在[用量日志](/usage-logs)核对实际明细。模型、分组和请求能力不同，计费方式也可能不同。

## 常见计费单位

| 单位 | 对应内容 |
| --- | --- |
| 输入 Token | 提示词、发送给模型的历史消息等输入 |
| 输出 Token | 模型生成的内容；推理等分类依模型而定 |
| 次／张 | 按请求或图片数量计费 |
| 秒 | 按音视频时长等用量计费 |
| 其他用量 | 模型或任务提供的专用计量项 |

Token 不等于字数。文本、图片、音频及不同模型的计量方式存在差异。

## 计算示例

假设价格为：输入每百万 Token 1 美元，输出每百万 Token 2 美元。一次请求输入 1,000 Token、输出 500 Token，则两项合计：

```text
输入费用 = 1,000 ÷ 1,000,000 × 1 = 0.001 美元
输出费用 =   500 ÷ 1,000,000 × 2 = 0.001 美元
合计 = 0.002 美元
```

这是解释单位的假设示例，不是 RouTok 报价。缓存、推理、图片、时长、价格档位和分组配置可能影响最终费用，应以实际明细为准。

## 预扣与结算

部分请求开始时会预留额度，完成后按系统规则结算。任务进行中的余额变化不一定等于最终费用。

超时、停止等待或关闭网页，不足以证明上游没有执行。重新提交前先检查任务和日志，避免重复生成。

## 控制预算

- 按应用创建独立密钥，设置适合用途的预算和有效期。
- 初次测试使用短提示词、小文件和单个任务。
- 长对话会重复携带历史消息；不再需要上下文时可新建会话。
- 定期核对用量，额度提醒仅作为辅助。

对费用有疑问时，提供调用时间、模型和记录标识，由[站内支持](/docs/support)协助核对。
