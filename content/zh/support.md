# 联系支持

账号、充值、套餐、模型开放和本站价格问题，请通过 RouTok 的站内支持渠道处理。调用问题可以先查看[错误排查](/docs/troubleshooting)。

## 查找联系方式

使用站内公告、页脚或[关于页面](/about)展示的联系方式。支付和账号问题不应提交到 New API 项目的公共问题区。

## 提供排查信息

以下信息有助于减少来回确认。复制模板，填写与你的问题相关的部分：

```text
希望完成的操作：
实际结果：
发生时间与时区：
使用位置：网页／客户端名称与版本／代码
API 地址（不含凭据）：
模型 ID 与接口类型：
HTTP 状态码与脱敏错误：
复现步骤：
发生频率：
Request ID／任务 ID／订单号（如有）：
已经尝试的检查：
```

充值问题请补充支付时间和金额；调用问题优先提供一条最小请求，将密钥替换为 `REDACTED`，私人输入替换为同类型的非敏感内容。

## 分享信息前检查

保留定位问题所需的状态、时间和记录标识。遮挡密码、验证码、恢复码、完整 API 密钥、浏览器登录令牌、完整支付凭据和私人文件。

## 等待处理期间

保留原始订单号或任务 ID，避免反复提交相同支付或生成请求。确认凭据泄露时，先停用并更换，再继续核对异常记录。
