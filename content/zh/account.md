# 注册与登录

RouTok 账号用于管理密钥、额度和调用记录。创建账号后，即可进入控制台完成接入准备。

## 注册账号

1. 打开[登录页面](/sign-in)，选择注册。
2. 按表单要求填写用户名、邮箱和密码。建议使用密码管理器生成独立密码。
3. 需要邮箱验证时，填写邮件中的有效验证码。
4. 完成注册并登录，确认[控制台](/dashboard)显示自己的账户信息。

没有注册入口时，可查看站内公告或[联系支持](/docs/support)了解账号开通方式。

## 选择登录方式

使用登录页提供的密码、第三方账号或通行密钥入口。账号启用了双因素验证时，按提示完成验证。

第三方登录提示创建新账号，而你已有账号时，先核对所选的第三方身份。关联登录方式应在已登录状态下通过[安全与访问](/security)完成。

## 找回密码

忘记密码时，打开[找回密码](/forgot-password)，使用绑定邮箱按提示重置。重置链接和验证码仅供本人使用。完成后重新登录，并检查[登录设备](/docs/security#检查登录设备)。

无法访问绑定邮箱或丢失验证设备时，请使用页面提供的恢复方式，或联系站内支持了解身份核验流程。

## 收不到验证码

依次检查邮箱拼写、垃圾邮件和邮件过滤规则；等待页面规定的发送间隔后再申请。收到多封邮件时，按页面提示使用仍有效的验证码。向支持反馈时提供发生时间和脱敏邮箱，无需提供验证码。

登录成功后，下一步是[创建 API 密钥](/docs/keys)。RouTok 账号与模型服务商账号相互独立，调用时使用本站签发的模型密钥。
