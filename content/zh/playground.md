# 在线测试模型

通过[在线测试](/playground)，可以在浏览器中体验模型并核对调用结果。测试会使用当前账号的可用额度，开始前请查看[模型价格](/pricing)。

## 完成一次测试

1. 登录并打开在线测试，选择模型和可用分组。
2. 保持默认参数，输入一个简短问题，例如“用三句话解释什么是 API”。
3. 发送后等待回复结束。
4. 打开[用量日志](/usage-logs)，核对模型、用量和费用。

收到完整回复并找到对应记录，即可确认这次测试成功。没有模型可选时，先检查可用分组，再联系支持确认开放范围。

## 调整参数

| 参数 | 作用 |
| --- | --- |
| 系统提示 | 描述任务、回答风格和约束 |
| 温度 | 调整输出变化程度，需模型支持 |
| 最大输出长度 | 限制单次输出上限，不代表一定生成该长度 |
| 上下文 | 本次请求带给模型的历史消息 |

每次只调整一个参数，并用相同问题比较，便于判断变化来源。

## 继续对话与重新生成

追问可能携带历史消息，增加输入用量。重新生成或编辑后重发属于新请求，可能产生新费用。停止等待或关闭网页不保证上游立即停止。

需要保存的内容请及时导出或复制。浏览器聊天记录不应作为唯一备份。

## 网页可用，客户端不可用

网页测试使用登录账号，客户端使用 API 密钥，两者的分组和访问限制可能不同。按[客户端接入](/docs/clients)核对地址、密钥、模型和分组。

侧边栏中额外配置的聊天入口可能指向第三方网站。使用前确认目标来源及隐私规则，避免分享含密钥的链接。
