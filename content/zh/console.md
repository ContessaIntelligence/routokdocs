# 认识控制台

控制台集中展示账户、模型、密钥和用量。首次使用，建议依次完成：**查看模型 → 确认额度 → 创建密钥 → 验证调用**。

## 常用入口

| 入口 | 主要用途 |
| --- | --- |
| [控制台](/dashboard) | 查看账户余额、请求量和近期用量趋势 |
| [模型广场](/pricing) | 查询模型 ID、支持能力和价格 |
| [API 密钥](/keys) | 创建调用密钥，设置额度、有效期和访问限制 |
| [在线测试](/playground) | 在浏览器中体验模型 |
| [钱包](/wallet) | 查看余额、充值订单、兑换入口和可用套餐 |
| [用量日志](/usage-logs) | 核对单次请求的模型、用量、耗时和费用 |
| [排行榜](/rankings) | 查看模型使用趋势 |
| [个人资料](/profile) | 管理个人偏好和通知设置 |
| [安全与访问](/security) | 管理登录方式、设备会话和个人访问令牌 |

菜单由网站配置和账号权限决定。缺少入口时先确认登录账号，再查看公告或[联系支持](/docs/support)。

## 看懂概览

![New API 数据看板示例，标出汇总指标、消耗趋势和调用趋势](/images/dashboard.zh-CN.jpg)

*数据看板示例：① 汇总指标，② 消耗趋势，③ 调用趋势。截图使用项目模拟数据，包含管理员视图；本站可见区域以账号权限为准。*

查看账户状态时，重点区分三个数字：

- **余额**：可用于调用的账户额度。
- **已用额度**：已经记录的消耗。
- **请求数**：调用次数，不能直接换算为费用。

## 找到一次具体调用

概览用于看趋势，明细请打开[用量日志](/docs/logs)。按调用时间和模型筛选，再展开对应记录。刚接入新软件时，完成一条短请求并找到对应日志，就能确认请求确实到达本站。
